# Isha Yadav — Portfolio

A personal portfolio built with React and Vite, with an Express API for the
contact form.

## Run locally

Start the API in one terminal:

```sh
cd Backend
npm install
npm run dev
```

Start the frontend in another terminal:

```sh
cd Frontend
npm install
npm run dev
```

The frontend runs at `http://localhost:5173` and proxies `/api` requests to the
API on port `5000`.
