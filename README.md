# Isha Yadav — Portfolio

A personal portfolio built with React and Vite.

![Portfolio homepage preview](image.png)



## 🛠 Set up

Requires **Node.js** and **npm**:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

## 🚀 Build and lint

```sh
npm run build
npm run lint
```
